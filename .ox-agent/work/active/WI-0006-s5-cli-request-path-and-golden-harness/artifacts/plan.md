# WI-0006 implementation plan — S5 request path + golden harness

Spec: `artifacts/spec.md` (sem-A..F construction, sem-R response,
sem-G degrade routing, harness contract, 12 deviations). Layout:
ADR-0020 (cli owns exec, Resp.hops), 0021 (committed fixtures),
0022 (stdin realpath), 0023 (jar-lite), 0024 (inert-vs-degrade).

## Stages

1. **Core model/wire extensions (TDD red-first)**
   - `core/model`: `ReqHead{method,uri,headers}`, `Hop{req_head,
     version,status,reason,headers,body,elapsed_ms,remote}`,
     `Resp.hops: own []Hop`, `Resp.version: str`.
   - `core/http/wire.oxl`: serialize_head `version` param +
     Host emitted LAST (update existing wire_test pins).
   - `core/http/h1.oxl`: parse_head records version; send() pushes
     each redirect hop (req head view + resp) into `hops`; jar-lite
     `Cookie` merge across hops (collect Set-Cookie name=values,
     emit `Cookie:` next hop — name-keyed, ADR 0023).
   - Gate: `core/http` tests green incl. new hops/version/host-last
     assertions.

2. **cli/req.oxl + sess/netrc (TDD)**
   - `cli/netrc.oxl`: parser per spec §D4 (NETRC env → ~/.netrc →
     ~/_netrc; machine/default/login/password/account/#/macdef).
   - `cli/sess.oxl`: session load (literal path vs
     `<cfg>/sessions/<host>[_port]/<n>.json`), HTTPie migrate,
     save_headers exclusions, persist pretty-JSON, RO rule.
   - `cli/req.oxl`: `fn plan(i: ref Intent, env: []str,
     stdin: []byte, stdin_tty: int) -> ReqPlan` — headers merge
     (spec order), body kinds, query, auth precedence, compress,
     session merge, warnings list. ReqPlan{req, warn, err, version10,
     sessctx}.
   - Tests: `cli/req_test.oxl`, `cli/sess_test.oxl`,
     `cli/netrc_test.oxl` — red then green.

3. **cli/print.oxl (TDD)**
   - req/resp head render (titlecase, latin1+UTF-8 annotate,
     canonical reason table), body emit (verbatim, BINARY_SUPPRESSOR),
     meta `Elapsed time: %.5fs` + `Remote address:`, separator rule,
     HumanBytes, download filename/progress, history-hop emit order.
   - Test: `cli/print_test.oxl`.

4. **cli/exec.oxl + sem/main wiring (TDD)**
   - `execute(i, env, stdin, stdin_tty) -> Run{code, stdout, stderr}`:
     ReqPlan → offline → transport (H1) → history/final print per
     sets → check-status(+warning) → download/-o/resume → session
     persist → digest 401 retry → degrade warnings.
   - `sem.oxl`: `Out.exec`; routing gains spec sem-G entries
     (curl/http2/proxy/resolve/interface/ipv6/unix/pretty!=none/
     format-options errors; debug warning; exec else).
   - `main.oxl`: stdin TTY via /dev/stdin realpath; read stdin when
     redirected; call execute; write bytes; quit.
   - Tests: `cli/exec_test.oxl` scripted-server matrix + updated
     `cli/sem_test.oxl` routing rows.

5. **Golden harness**
   - `tests/golden/cases/*.case` (argv/stdin/env/script/files),
     `tests/golden/fixtures/*.{stdout,stderr,exit}` generated by
     `scripts/golden-gen.sh` + `scripts/golden-server.py` against
     real xh 0.26.3 (`$OXTPP_XH` or PATH); `tests/golden/README.md`.
   - `cli/golden_test.oxl`: case parser, adapted scripted server,
     normalizer+comparator, asserts execute() vs fixtures.
   - Cases per spec's corpus-row list (~40).

6. **Verify + ship**
   - dir-loop `oxl test` green; `oxl build ./cli`; live smoke vs
     local fixture server; CHANGELOG Unreleased; commit
     `feat(cli): request path — intent→model→h1, xh output shaping,
     golden harness`; push; PR; `gh pr checks` green.

## Dependencies

- req.oxl → model, item (kinds), json (jadd/jstr/jparse), url
  (queryescape), base64, zlib? (compress → std/compress/zlib),
  md5 (digest), sess/netrc locals.
- exec.oxl → req, print, sess, model, http.H1, os.
- print.oxl → model (+json for nothing — verbatim only).
- golden_test → exec, os, net, strings, strconv, testing.

## Risks

- `own` graph churn on Intent/ReqPlan/Run — same copy-out patterns
  as S4.
- Session cookie→jar shape vs upstream dedup — jar-lite bounded by
  ADR 0023 + spec'd gap note.
- Golden fixture volatility — normalizer must cover prog/UA/AE/Conn/
  elapsed/remote/boundary/digest; escape hatch = add normalize rule,
  never blanket-ignore.
- Digest md5 flow — std md5 verified present; cnonce env hook keeps
  fixtures deterministic.
- `oxl test` cwd — golden reads `tests/golden/` relative; dir-loop
  runs from repo root (config.yaml pins this).
