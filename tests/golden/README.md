# Golden differential harness (xh ↔ oxttp)

Committed fixtures generated by real `xh 0.26.3` — CI replays them
without xh installed. `cli/golden_test.oxl` loads each case, runs
`execute()` against the in-test scripted server, normalizes known
deviations (UA, Accept-Encoding, Connection, timings, addresses),
and diffs stdout/stderr/exit vs the xh captures.

## Case format (`cases/*.case`)

Line-oriented `key: value`; `#` comments:

    argv: post {URL} a=1 n:=2        # argv after prog; {URL}→server url
    stdin: <literal body>            # optional (presence = piped stdin)
    env: NAME=value                  # repeatable
    script: <resp> ;; <resp> ...     # one entry per connection; each is
                                     #   `STATUS REASON\nHeader: v\n\nbody`
                                     #   or the literal `<ECHO>`
    files: <path><TAB><content>      # repeatable pre-state files (relative
                                     #   to a fresh temp dir the runner cds)

Regenerate fixtures: `OXTPP_XH=/path/to/xh ./scripts/golden-gen.sh`
(builds oxttp, serves scripts/golden-server.py, writes
`fixtures/<case>.{stdout,stderr,exit}`).
